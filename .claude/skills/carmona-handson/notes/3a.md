# 3a · Security · Overview

Source: https://insper.github.io/platform/2026.2/hands-on/3/

- Three modules: `auth` (Feign `AuthController` + DTOs), `auth-service` (JWT issue, delegates account creation to `account`), `gateway-service` (single entry point, enforces auth in a global filter).
- Trusted layer: internet → gateway → {auth, account, others} → DB. Only the gateway is reachable from outside.
- Reference `AuthController`: `login(LoginIn)`, `register(RegisterIn)`, `whoIAm(id-account)`, `solveToken(TokenOut)`, `logout()`, `healthCheck()`.
- DTOs: `LoginIn(email, password)`, `RegisterIn(name, email, password)`, `TokenOut(token)`.

## Carmona overrides

- No `solveToken` / `/auth/solve`: the gateway validates RS256 tokens locally from auth's JWKS (`GET /auth/jwks`, internal).
- No `healthCheck` endpoint: actuator probes on management port 8081.
- `whoami` kept (`GET /auth/whoami`, reads `id-account`).
- Token transport: `Authorization: Bearer` (working default), so logout has nothing to clear server-side and is not built yet.
