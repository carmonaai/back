# 3c · Security · Open Routes

Source: https://insper.github.io/platform/2026.2/hands-on/3/open-routes/

- Open routes: `POST /auth/register`, `POST /auth/login`, `GET /auth/logout`. Everything else needs a valid token.
- `auth-service`: `AuthApplication` (`@EnableFeignClients(basePackages="…account")`), `AuthResource implements AuthController`, `AuthService` (register → `accountController.create`, login → account credential check → `jwtService.generate`), `JwtService`.
- Login flow: `POST /auth/login` → account checks email+password → `AccountOut` → sign JWT → return token.

## Carmona overrides

- Credential check is `POST /accounts/login` on account-service (Argon2id verify, constant-ish time on unknown email). Internal only, never routed by the gateway.
- Login returns `TokenOut` in the body (Bearer), not a cookie.
- Feign calls to account run through Resilience4j (circuit breaker + bulkhead + timeouts). 4xx from account are ignored by the breaker and passed through as-is (400/401/409).
- `GET /auth/logout` dropped: GET with side effects, and nothing to clear with Bearer tokens.
