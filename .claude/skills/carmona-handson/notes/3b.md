# 3b · Security · JWT

Source: https://insper.github.io/platform/2026.2/hands-on/3/jwt/

- `auth` is a library like `account`: openfeign + lombok, depends on `account` at `${project.version}` (whoami returns `AccountOut`). `mvn clean install` so services resolve it.
- `@FeignClient(name="auth", url="http://auth:8080")`; DTOs are `@Builder` records.
- Reference token: HS256 (JJWT), `jti`=account id, `sub`=name, `email` claim, `nbf`/`exp`, 24 h, delivered as `HttpOnly; Secure; SameSite=None` cookie `__store_jwt_token`.

## Carmona overrides

- RS256 signed with Nimbus via `spring-security-oauth2-jose` (`NimbusJwtEncoder`), not JJWT.
- Claims: `iss=ai.carmona`, `sub`=account id, `iat`, `exp`. No name or email in the token (LGPD: ids only).
- Lifetime 15 min (rule: 5–60 min).
- Private key from env `JWT_PRIVATE_KEY` (base64 PKCS#8 DER); public key derived from it; `kid` = RFC 7638 thumbprint. Never a default value.
- Bearer header instead of the cookie (pending decision; cookie flags above apply if it ever changes).
